# FreePBX / Asterisk setup

cam2sip registers to your PBX like any SIP desk phone. Each bridge needs one extension.

## FreePBX (16/17, chan_pjsip)

1. **Applications → Extensions → Add Extension → Add New SIP [chan_pjsip] Extension**
2. General tab:
   - **User Extension**: e.g. `1008`
   - **Display Name**: e.g. `Front Door`. This is what your phones show.
   - **Secret**: copy it. cam2sip needs it as the phone *Password / secret*.
3. Advanced tab (defaults are fine, but check these):

   | Setting | Recommended | Why |
   |---|---|---|
   | Transport | `0.0.0.0-udp` (or *All*) | cam2sip speaks SIP over UDP |
   | Disallowed / Allowed Codecs | `ulaw`, `alaw` allowed | cam2sip only does G.711 |
   | Direct Media | `No` (default) | RTP goes through Asterisk; simplest with firewalls |
   | Media Encryption | `None` | SRTP isn't supported |
   | NAT Mode / rewrite_contact | default (`No` on a LAN) | cam2sip advertises its real LAN IP |
   | Max Contacts | 1 (default) | cam2sip registers once per extension |

4. **Submit** and **Apply Config**.
5. In cam2sip, go to **Virtual phones → Add phone**:
   - **PBX host**: the FreePBX IP, **SIP port**: `5060`.
   - **Extension**: `1008`, **Password**: the secret from step 2.
   - The badge should turn **registered** within a second or two.

Check it on the PBX with **Reports → Asterisk Info → Registries/Peers**, or from the CLI:

```bash
asterisk -rx "pjsip show contacts" | grep 1008
# Contact:  1008/sip:c2s-1a2b3c4d@192.168.1.20:5062   ...  Avail
```

The contact user (`c2s-xxxxxxxx`) is generated by cam2sip. Incoming calls are routed by it, so several virtual phones can share one port.

## Useful FreePBX features with cam2sip

- **Ring groups**: add the camera's "doorbell" target, e.g. ring group `600` containing your desk phones, and let the bridge dial `600` from an automation (see [api.md](api.md)).
- **Echo test (`*43`)**: `tools/sip_test_call.py --target *43` checks registration and RTP without involving a camera.
- **Paging / intercom**: you can include the virtual extension in paging groups. cam2sip auto-answers, so a page plays through the camera speaker.
- **Firewall module**: if the FreePBX firewall is enabled, add the cam2sip host to *Trusted*, or the registration may be blocked.

## Plain Asterisk (pjsip.conf)

```ini
[1008]
type=endpoint
context=from-internal
disallow=all
allow=ulaw,alaw
auth=1008-auth
aors=1008
direct_media=no

[1008-auth]
type=auth
auth_type=userpass
username=1008
password=SuperSecret

[1008]
type=aor
max_contacts=1
qualify_frequency=60
```

## Other PBXs

Any PBX that accepts a UDP SIP registration with digest auth and G.711 should work (3CX, FusionPBX/FreeSWITCH, Yeastar, Grandstream UCM, FRITZ!Box…). Set **SIP domain** if the registrar expects a domain different from its IP, and **Auth username** if the auth ID differs from the extension number.
